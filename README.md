# Machine Class Is the Message — analysis code and outputs

Analysis code, inputs, and outputs for the paper:

**Sajish Krishnan, "Machine Class Is the Message: Confounding and Request-Shape Effects in GPU Cluster Task Failures"** (2026). Preprint: arXiv (link added on posting). Data and code archive: Zenodo (DOI added on posting). Author ORCID: [0009-0009-7561-9290](https://orcid.org/0009-0009-7561-9290).

The paper characterizes a derived GPU-cluster feature matrix: 18,890 tasks with the label Failed vs Terminated, drawn from the Alibaba Cluster Trace GPU v2020 via the KANVAS project. Its main findings are that machine class is the largest univariate split in the data, that the pooled "busy machine" association is largely Simpson's paradox, and that quarter-GPU requests on 8-GPU machines form an anomalously high-Failed-share cell. Every number in the paper is produced by the scripts in this repository from the files in `data/`.

## Provenance — read this before citing the data

The dataset analyzed here is **not** the raw Alibaba trace. It is the feature matrix released by the **KANVAS project** as `Swapnil007-Curious/kanvas-gpu-failure` on Hugging Face, itself derived from the **Alibaba Cluster Trace GPU v2020** (Weng et al., "MLaaS in the Wild," USENIX NSDI 2022). The label is Failed vs Terminated among tasks that ended; the headline 27.5% figure is P(Failed | Failed or Terminated) in this filtered subset and is **not** a cluster failure rate. Please cite the data the same way.

## Layout

- `data/` — the exact input files used, downloaded 16 November 2026: `kanvas_feature_matrix.csv`, `kanvas_phi_curves.csv`, `kanvas_benchmark_results.csv`, plus the dataset's own `kanvas_README.md` and `data_dictionary.md`. `download.sh` re-fetches the same files from Hugging Face.
- `scripts/eda.py` — schema/integrity checks, univariate effect sizes, the multivariate model. Writes `scripts/eda_results.json`.
- `scripts/stratified.py` — within-machine-class analyses: quartile rates, context-only vs context+class models, models refit within each class. Writes `scripts/stratified_results.json`.
- `scripts/charts.py` — the four paper figures. Writes `charts/*.png`. (Run after `eda.py`; it reads `eda_results.json`.)
- `charts/` — the generated figures.
- `requirements.txt` — the environment used (Python with pandas 3.1.1, scikit-learn 1.9.1, numpy 2.5.5, scipy 1.18.1, matplotlib 3.11.2).

## Reproducing

```sh
pip install -r requirements.txt
python scripts/eda.py
python scripts/stratified.py
python scripts/charts.py
```

All random splits use seed 42. The committed `*_results.json` files are the outputs the paper's numbers were taken from; re-running the scripts in the environment above regenerates them.
